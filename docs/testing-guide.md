# Гайд по тестированию (пакеты 8–9)

Что проверить в новой сборке, как это выставить и что должно получиться.
Порядок — от безопасного к станку. Отмечайте пункты `[x]` по ходу и пишите,
на каком пункте что-то пошло не так.

Объект проверки — ваша панель `plant_sensor/cnc/panel_rev0.3`: Gerber,
Excellon PTH/NPTH и контур платы.

---

## 0. Подготовка (5 минут)

- [ ] Сделайте копию `%APPDATA%\XrSoft\GGEasy\tools.json` и папки `scripts`
  старой версии.
- [ ] Распакуйте `GGEasy-windows-zip` из CI в **новую** папку.
- [ ] Запустите программу. Ожидается:
  - рядом с `tools.json` появился `tools.json.bak` — это исходник;
  - в `tools.json` у инструментов появились `uid` и `code`, в корне —
    `materials`;
  - в `scripts\` новой папки у файлов, которые вы меняли, лежат копии
    `*.bak`.
- [ ] Настройки → G-Code: в каждой вкладке плагина путь к скрипту ведёт в
  `scripts\` **новой** папки. Если указан старый путь, нажмите
  «По умолчанию».
- [ ] Настройки → G-Code → постпроцессор **grblHAL**.

## 1. Свойства проекта

Откройте проект панели. В «Свойства G-кода»:

- [ ] Безопасная высота (safeZ), отвод (clearence) и врезание (plunge) —
  ваши обычные значения. От плоскости врезания отсчитывается R циклов
  сверления.
- [ ] «Материал заготовки» — **FR4**. Новый проект потом начнётся с него
  сам.

## 2. База инструментов (Сервис → База инструментов)

- [ ] **Коды.** У каждого инструмента есть «Код», например:
  - `D08L90` — сверло 0,8 с длиной 9;
  - `D035L50` — сверло 0,35 с длиной 5;
  - `M05L20` — фреза 0,5 с длиной 2;
  - `V02A30` — гравёр 0,2 / 30°;
  - `L005` — лазер.

  Длина рабочей части 1,0 и меньше считается не заданной: тогда в коде нет
  `L…`, как у сломанных свёрл с длиной 0,1. Поле называется «Длина рабочей
  части». Пока стоит галка «авто», код меняется вместе с диаметром и
  длиной.
- [ ] **Формат кода** — разовая настройка в `tools.json`, ключ `codeFormat`
  (шаблон на тип: `{D}`, `{L}`, `{d}`, `{l}`, `{A}`, необязательная часть в
  `[ ]`). Без ключа — по умолчанию (`D{D}[L{L}]`, `M{D}[L{L}]` …).
- [ ] **Повтор кода.** Одинаковые коды у разных инструментов допустимы
  (например, сверло 0,7 / 9 из двух наборов): ни окна, ни подсказки нет.
- [ ] **Сверло.** Кнопка «+» в «Режимы резания» предлагает только
  «Сверловка». Режимов фрезеровки у сверла нет.
- [ ] **Наборы режимов для одного сверла, например 0,8:**
  - «+» → «Сверловка · FR4» → обороты, врезание, проход → «Применить»;
  - «Цикл сверления» — «Авто»;
  - «Выдержка» — 0;
  - «Отвод на R (G99)» — выключено. Включайте, только если над платой нет
    булавок выше плоскости R.
- [ ] **Наборы режимов для фрезы 0,5:**
  - «Сверловка · FR4» — врезание;
  - «Фрезеровка · FR4» — подача, проход, шаг.
- [ ] **Нулевые поля.** Наберите в каком-нибудь наборе подачу 0 и нажмите
  «Применить». Должен быть отказ с названием набора.
- [ ] **Материалы.** «Материалы…» показывают 7 материалов. Добавьте и
  переименуйте материал. Удаление материала, у которого есть наборы,
  спрашивает подтверждение.
- [ ] **Лазер.** У лазерного инструмента, в собственных значениях и в
  наборах «Лазер · Фоторезист» / «Лазер · Паяльная маска», есть галка
  «Динамическая мощность (M4)». У каждого набора она своя.

## 3. Форма «Сверловка» (новая)

- [ ] Групп «Тип работы», «Расположение» и «Направление» больше нет. В
  таблице есть столбец «Режим», у всех строк стоит «Сверловка».
- [ ] «Подобрать инструменты» назначает свёрла строкам сверловки.
- [ ] Двойной щелчок по инструменту строки открывает базу с **подсвеченным
  текущим инструментом**.
- [ ] **Сверло.** У строки со сверлом в списке «Режим» карман и профиль
  серые, подсказка «Сверло только сверлит…».
- [ ] **Фрезеровка отверстий.** Отверстиям 0,65 назначьте фрезу 0,5 и
  режим «Профиль · попутное», или «Карман · …» для крупных.
- [ ] **Обратная смена.** Назначьте такой строке сверло: она сама
  переходит на «Сверловка».
- [ ] **Выделение.** Выделите несколько строк и выберите режим в одной из
  них — он применяется ко всем выделенным. Меню заголовка «Режим для всех»
  ставит режим всем строкам.
- [ ] **Колесо мыши** над столбцом «Режим» листает таблицу и не меняет
  режим.
- [ ] **Один «Создать»** даёт УП сверловки по свёрлам и отдельные УП
  фрезеровки: `M-D0.5MM_PROFILE` и при необходимости `_POCKET`…
  - Всё попадает в группу файла сверловки.
  - Ни одна УП не пустая.
  - Предупреждения «инструмент не помещается» нет.
- [ ] **PTH и NPTH.** Сделайте «Создать» на PTH, переключите файл на NPTH и
  снова «Создать». УП PTH остаётся, рядом появляется УП NPTH.
- [ ] **«Обновить».** Двойной щелчок по УП сверловки в дереве → «Обновить».
  УП заменяется на месте, копии рядом нет.

## 4. G-код сверловки (окно УП или сохранённый файл)

Постпроцессор grblHAL, сверло 0,8 с набором «Сверловка · FR4».

- [ ] **Один проход** (Pass ≥ глубины): строка `G98`, затем
  `G81X…Y…Z…R<plunge>F…`, затем `X…Y…` по отверстиям, `G80`,
  `G0Z<clearence>`.
- [ ] **Pass меньше глубины, «Авто».** grblHAL поддерживает G73, G81–G89,
  но его G83 после каждого клевка уходит вверх на R (при G98 — на высоту
  отвода) и опускается обратно **на рабочей подаче** через уже
  просверлённое. Для 0,5 мм с проходом 0,1 мм это 17 клевков на отверстие и
  секунды на каждом. Поэтому «Авто» на grblHAL пишет клевки развёрткой:
  - `G0Z<R>`;
  - `Z<прошлое дно + 0.2>` — быстрым ходом;
  - `G1Z<следующий клевок>`;
  - ниже уже просверлённого быстрым ходом не идёт.

  Один проход (Pass ≥ глубины) — канонический `G81`. Если нужен именно
  `G83` контроллера — выберите «G83» в цикле сверления набора.
- [ ] **«Цикл сверления: G83» явно:** `G83 … Q…`. С «Отвод на R» перед
  циклом стоит `G99`.
- [ ] **«G82 с выдержкой», выдержка 0,3 с:** `G82 … P0.3`.
- [ ] **3D-просмотр.** Цикл виден ходами, как на станке.
- [ ] **Глубина при нескольких проходах** теперь тоже включает конус
  сверла, как при одном проходе. Для 0,8 / 118° это примерно на 0,24 мм
  глубже, чем раньше. Проверьте, что подложка это выдерживает.

## 5. Фрезеровка и вырезка

- [ ] Форма «Профиль»: контур платы, «Снаружи», фреза 1,0, материал проекта
  FR4. Подача и обороты берутся из набора «Фрезеровка · FR4». Подсказка у
  инструмента: «Режимы: Фрезеровка · FR4».
- [ ] «Редактировать» → изменить подачу. Имя инструмента показывается
  курсивом со `*` и больше не следует за материалом.

## 6. Лазер (HLDI, растр)

- [ ] Форма «Растр», лазерный инструмент. Вместо «Проход профиля» здесь
  галка **«Обвести контур после растра»**. У фрезы по-прежнему список.
- [ ] Обводка с галкой: в конце УП, после всех строк растра, идут контуры.
  Так и в обычном режиме, и в HLDI.
- [ ] **HLDI, разгоны и промежутки:**
  - разгоны и развороты за краем и промежутки внутри строк идут как
    `G1 X… S0`;
  - пустых строк `G0S0` нет;
  - засвечены только отрезки растра.
- [ ] **Направление HLDI.** Если выбрать тип «HLDI», в «Направлении» вместо
  «Попутное / Встречное» появляется «Двунаправленный / Однонаправленный».
  - «Двунаправленный» — змейка, как раньше.
  - «Однонаправленный» — все строки засвечиваются в одну сторону, возврат
    между строками идёт `G1 … S0`.
  - На пробной засветке края однонаправленного растра без зубцов через
    строку.
- [ ] **M3 и M4:**
  - набор лазера **без** «Динамическая мощность» даёт `M3` после первой
    строки `G0 X… Y… S0`;
  - с галкой — `M4`.
- [ ] **Тест на обрезке фоторезиста.** Засветите маленький участок и
  проверьте: полос за краем платы нет, медь между площадками не засвечена,
  края ровные.

## 7. Задание («Сохранить как задание…»)

Сценарий «до металлизации»: сверловка PTH и фрезеровка отверстий.
«После металлизации»: NPTH и вырезка.

- [ ] Отметьте **галочками** нужные УП в дереве: только одну сторону, без
  лазера. Затем «Файл → Сохранить как задание…» или ПКМ по УП.
  Выделение двух УП и больше, или группы целиком, тоже работает.
- [ ] **Окно задания:**
  - порядок: свёрла по возрастанию, потом фрезы; внутри инструмента
    сверловка раньше фрезеровки; вырезка последней, флажок «Вырезка —
    последней» поставлен сам;
  - T жирный там, где перед шагом смена;
  - между шагами одной фрезы T не жирный;
  - «Номера инструментов до T» — «без ограничения». Поставьте 8: при
    9 и более инструментах появится предупреждение, номера пойдут по кругу.
    Верните «без ограничения»;
  - «Вверх», «Вниз», «Порядок по умолчанию» работают.
- [ ] **В файле:**
  - в шапке `G21 G17 G90`, `G94`, без `M3`;
  - `;FORMAT GGEASY-JOB 1`, `;JOB …`, `;SIDE TOP`, `;MATERIAL FR4`,
    `;STEP …`, `;TOOLS n`;
  - строки инструментов вида `;T1 D03L50 D=0.30 DRILL HITS=…`;
  - первая смена: `G0Z<safe>`, `M61 Q0`, `M5`, `(MSG, T1 …)`, `T1 M6`,
    `M3 S…`, `G0Z<safe>`;
  - между шагами одного инструмента `M6` нет, только `M3 S<новые>`, если
    обороты разные;
  - в конце один раз `M5`, `M2`;
  - поиском: **нет** `G43`, `G43.1`, `G49`, `G10`.
- [ ] **Отказы:**
  - УП обеих сторон → сообщение;
  - лазер вместе с фрезой → сообщение;
  - пустая УП → «Пропущены, нет траекторий».
- [ ] **«Сохранить выбранные…»** (видимые УП): один файл на физический
  инструмент, внутри сверловка раньше фрезеровки, без `M6`.

## 8. На станке (grblHAL `$341=1`, крокодил, ncSender)

Сначала — **в воздухе**: ноль Z на 10 мм выше заготовки, подача 50 %.

- [ ] Загрузите файл задания в ncSender и проверьте в нём список строк.
- [ ] **Старт:**
  - `M61 Q0`;
  - на `T1 M6` контроллер останавливается, ncSender показывает сообщение
    `T1 D… DRILL D=…`;
  - смена сверла, касание крокодилом (`$TPW` = 0), продолжение.
- [ ] **После смены:**
  - шпиндель запускается (`M3 S…`);
  - Z уходит на safeZ;
  - только потом ход по XY.
- [ ] **Между шагами одним инструментом** (сверловка и фрезеровка фрезой
  0,5) остановки нет.
- [ ] Каждая следующая смена идёт так же. В конце `M5`, `M2`, Z на safeZ.
- [ ] Затем **реальный прогон** на обрезке FR4: глубина отверстий,
  клевки, профиль 0,65, вырезка.

## 9. Если что-то не так — что прислать

- `.nc` — задание или УП — и номер строки или шага;
- `.g2g` проекта и `tools.json`;
- снимок экрана окна, например формы сверловки или окна задания;
- что ожидали и что получилось.
